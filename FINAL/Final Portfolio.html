During these weeks, we worked with Javascript and P5 to create images, more specifically a self portrait on a blank HTML page.
First week we plotted out the shapes, the text, and the images. Then the next we used logical operators

Week 11-13: Website Development


In these final weeks, we were tasked with creating a game using Javascript and P5. The premise of the game was to create multiple obstacles as the player (Blue ball, top left)
would move to the opening labled exit. We used "If" statements to make enemy circles come back after they cross the border on the other side of the map.
Then we used logical operators to make one of the balls do something, (such as expand to a certain point) and we use code for a mouse input to make another circle.
On the final week, then we attempted to use arrays to create more randomly moving shapes that go across the playspace.
